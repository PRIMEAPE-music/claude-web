# Claude Web

Web interface for Claude Code CLI with real-time streaming, project management, and mobile support.

## Architecture

```
server.js          - Express + Socket.IO server, handles all API/socket events
claude-runner.js   - Spawns Claude CLI processes, manages sessions
database.js        - SQLite database layer (better-sqlite3) for projects/tasks
mcp-client.js      - MCP server communication
memory-service.js  - Knowledge graph integration
puppeteer-service.js - Browser automation support
auth.js            - Socket authentication middleware

public/
  index.html       - Single-page app UI
  client.js        - Frontend Socket.IO client, all UI logic
  style.css        - Styles (dark theme, responsive)
  sw.js            - Service worker for PWA/notifications
```

## Key Features

- **Real-time streaming**: Claude responses stream via Socket.IO as they're generated
- **Session management**: Persistent sessions with conversation history
- **Project management**: SQLite-backed projects, tasks, folders, conversation linking
- **Model selection**: Switch between opus/sonnet/haiku per session
- **Image support**: Upload and attach images to prompts
- **MCP integration**: Memory graph, puppeteer tools available
- **Push notifications**: Web push for long-running tasks
- **Mobile app**: Capacitor-based Android build

## Development

```bash
npm run dev    # Start with --watch for auto-reload
npm start      # Production start
```

## Environment Variables

```
PORT=3456                    # Server port (default: 3456)
AUTH_TOKEN=<token>           # Optional auth token for socket connections
VAPID_PUBLIC_KEY=<key>       # Web push public key
VAPID_PRIVATE_KEY=<key>      # Web push private key
```

## Database

SQLite database stored at `~/.claude/claude-web/claude-web.db`:

- `projects` - Project definitions with working dir, model, context files
- `tasks` - Tasks linked to projects (backlog, in_progress, done)
- `folders` - Conversation organization within projects
- `conversation_links` - Links conversations to projects/folders
- `settings` - Key-value settings (active project, etc.)

## Socket Events

### Session

- `create-session` / `session-started`
- `restore-session` / `session-restored`
- `send-message` / `claude-response`, `claude-done`
- `stop-generation` / `generation-stopped`

### Conversations

- `list-conversations` / `conversations-list`
- `load-conversation` / `conversation-loaded`
- `delete-conversation` / `conversation-deleted`

### Projects

- `project-list`, `project-create`, `project-update`, `project-delete`
- `project-activate`, `project-get-active`

### Tasks

- `task-list`, `task-create`, `task-update`, `task-delete`

### Folders

- `folder-list`, `folder-create`, `folder-update`, `folder-delete`

### Conversation Links

- `conversation-link`, `conversation-unlink`
- `conversation-move-to-folder`
- `conversation-list-by-project`

## Claude Runner

The runner spawns Claude CLI with:

- `--output-format stream-json` for real-time token streaming
- `--include-partial-messages` for agent/Task tool output
- `--dangerously-skip-permissions` (runs in trusted environment)
- Working directory validation with HOME fallback

## Systemd Service

Install as user service:

```bash
./install-service.sh
systemctl --user start claude-web
systemctl --user enable claude-web
```

## Mobile Build

Uses Capacitor for Android:

```bash
npx cap sync android
npx cap build android
```

APK output copied to `~/Projects/Webapps/APK/claude-web-<variant>.apk`
